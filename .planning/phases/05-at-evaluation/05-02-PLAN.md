<objective>
Execute the D-15 pre-flight sanity check: load the AT checkpoint via the new
Plan 01 shim, run a quick per-(mod, SNR) clean accuracy check, and record the
result as a human-verified gate before launching the 2–4h full defense_compare
matrix in Plan 03.

Purpose: Guards against state_dict key drift between the Phase 4 saver and the
Phase 5 loader (torch.save + weights_only=True). If keys don't line up or if
the model silently loads zeros (e.g., strict=False masking everything), the
full matrix run would consume hours on bad data. Also cross-checks D-08
(analog-mods-kept-clean) preserved WBFM/AM-DSB/AM-SSB accuracy — if clean WBFM
is near chance, the AT finetune forgot analog classes and Phase 5 would
produce misleading numbers for those rows.

Output: A sanity-check log at `.planning/phases/05-at-evaluation/05-02-sanity.log`
recording the two accuracies (QPSK@18dB, WBFM@18dB) plus a compact checkpoint
keys summary, and a human-verify checkpoint that confirms the numbers are
plausible before Plan 03 launches the expensive full run.
