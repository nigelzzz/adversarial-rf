**Part A: `randomized_smoothing_predict(model, x, *, k=20, sigma=0.01)`** (per D-08: k=20, D-09: sigma=0.01, D-10: classifier wrapper)
- `x`: shape `[N, 2, T]`, model: AWN model (returns `(logits, regu_sum)`).
- Expand: `x_rep = x.unsqueeze(0).expand(k, -1, -1, -1).reshape(k*N, C, T)`.
- Add noise: `x_noisy = x_rep + torch.randn_like(x_rep) * sigma`.
- Forward pass with `torch.no_grad()`: `logits, _ = model(x_noisy)` -> `[k*N, num_classes]`.
- Reshape preds: `preds = logits.argmax(dim=1).reshape(k, N)` -> `[k, N]`.
- Majority vote: use `torch.zeros(N, num_classes, device=x.device)`, scatter_add ones at pred indices, return `votes.argmax(dim=1)` -> `[N]`.
- Wrap in try/except for OOM: if CUDA OOM, fall back to micro-batch of size N (process k copies one at a time, accumulate votes).

**Part C: `defend(x, model, detector, cfg)` unified pipeline** (per D-07)
- Signature: `def defend(x: torch.Tensor, model, detector, cfg) -> tuple[torch.Tensor, dict]:`
- Returns `(predictions: [N], latency_breakdown: dict)` where latency values are per-sample ms.
- Reads `cfg.defense` (string name) to dispatch.
- **Special path for `rand_smooth`** (per D-10): call `randomized_smoothing_predict(model, x, k=getattr(cfg, 'rs_k', 20), sigma=getattr(cfg, 'rs_sigma', 0.01))`, time the whole thing, return predictions directly (no separate filter step).
- **Standard path for signal filters**:
  1. **Detector** (if detector is not None and cfg has threshold): time with `torch.cuda.Event` (per D-11), compute KL via `normalize_for_detector` + `detector(x_norm)` + `kl_divergence_timewise`. Record `latency_breakdown['detector_ms']`.
  2. **Recovery/Filter**: look up `DEFENSE_REGISTRY[cfg.defense]`, call it with kwargs from cfg (e.g., `cfg.def_topk` for fft_topk). If filter is GPU-native, time with `torch.cuda.Event`; if CPU, time with `time.perf_counter` (per D-11). Record `latency_breakdown['filter_ms']`.
  3. **Classifier**: `model(x_filtered)` -> logits. Time with `torch.cuda.Event`. Record `latency_breakdown['classifier_ms']`.
  4. Return `(logits.argmax(dim=1), latency_breakdown)`.
- Per D-12: divide batch timing by N for per-sample values.
- Per D-13: include 3 warmup calls before measurement in a `_warmup(fn, x, n=3)` helper.
- CPU vs GPU timing selection: `gaussian`, `fir`, `fft_topk`, `spectral_gated` use `torch.cuda.Event`; `kalman`, `wiener`, `savitzky_golay` use `time.perf_counter`.
