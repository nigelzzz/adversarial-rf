Note on hyperparameter discrepancy (CONTEXT.md D-05 vs sigguard_eval.create_attack defaults):
- D-05 states paper-default hyperparameters: FGSM eps=0.03; PGD eps=0.03/steps=10/alpha=0.01;
  CW c=1.0/steps=100/lr=0.01; EADL1 steps=100; EADEN steps=100; ta_box=unit.
- create_attack() actual defaults: CW c=10.0, steps=200, lr=0.005; PGD steps=10, alpha=eps/4
  (i.e., 0.0075 if eps=0.03); EAD max_iterations=100; FGSM eps=cfg.attack_eps default 0.03.
- The bench MUST present cfg with paper-default values so create_attack() returns the
  D-05-locked attack objects. This means setting cfg.cw_c=1.0, cfg.cw_steps=100,
  cfg.cw_lr=0.01, cfg.attack_eps=0.03, cfg.ta_box='unit' inside the bench function
  (or via main.py CLI in Plan 02 — Plan 02 owns the CLI defaults). For PGD alpha,
  D-05 requires 0.01; create_attack derives alpha = eps/4 = 0.0075 when eps=0.03,
  so the bench MUST patch cfg.attack_eps=0.04 OR call torchattacks.PGD directly
  with alpha=0.01. Cleanest path: do not duplicate the attack factory; instead
  set cfg.attack_eps=0.03 and accept alpha=0.0075 (note in module docstring as
  the divergence from D-05 PGD alpha=0.01). The latency delta from alpha is
  negligible because PGD timing is dominated by the 10 inner steps' forward/backward.
- IMPORTANT: Document this trade-off in the module docstring so reviewers see
  exactly which hyperparameters were used.

   - Returns a 1-D LongTensor of indices into sig_test (length == n_samples).
   - Uses `np.random.default_rng(seed)` for deterministic shuffles.

6. Helper `def _time_one_cell(attack, sig_iq, lab, wrapped_model, ta_box, batch_size, warmup, n_reps, device) -> Tuple[float, float, float]`:
   - Returns `(mean_ms_per_sample, std_ms_per_sample, total_seconds_across_reps)`.
   - For each warmup iter: chunk sig_iq into batches of size `batch_size`, call generate_adversarial on each batch. Discard timings.
   - For each of n_reps timed iters:
     ```python
     if device == 'cuda':
         torch.cuda.synchronize()
     t0 = time.perf_counter()
     for batch_x, batch_y in batches:
         _ = generate_adversarial(attack, batch_x, batch_y, wrapped_model=wrapped_model, ta_box=ta_box)
     if device == 'cuda':
         torch.cuda.synchronize()
     t1 = time.perf_counter()
     per_sample_ms_list.append(((t1 - t0) / n_total_samples) * 1000.0)
     ```
   - Returns `mean(per_sample_ms_list), std(per_sample_ms_list, ddof=0), sum_of_block_seconds`.
