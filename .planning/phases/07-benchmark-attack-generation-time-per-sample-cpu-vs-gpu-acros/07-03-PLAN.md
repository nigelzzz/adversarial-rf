3. Module constants:
   ```python
   ATTACK_ORDER = ['fgsm', 'pgd', 'cw', 'eadl1', 'eaden']
   ATTACK_DISPLAY = {'fgsm': 'FGSM', 'pgd': 'PGD', 'cw': 'CW', 'eadl1': 'EAD-L1', 'eaden': 'EAD-EN'}
   DEVICE_ORDER = ['cpu', 'cuda']
   DEVICE_DISPLAY = {'cpu': 'CPU', 'cuda': 'GPU'}
   DEVICE_COLORS = {'cpu': DEFENSE_COLORS['no_defense'], 'cuda': DEFENSE_COLORS['adaptive_k']}
   ```

4. Helper `def _resolve_default_csv() -> str:`
   - `paths = sorted(glob.glob('inference/2016.10a_*/result/attack_bench.csv'))`
   - If empty: raise FileNotFoundError with a descriptive message instructing the user to run `python main.py --mode attack_bench --dataset 2016.10a --ckpt_path ./checkpoint` first.
   - Else return `paths[-1]` (most recent by lexicographic sort, which is also chronological because the index auto-increments).

5. Helper `def _load_and_validate(csv_path: str) -> pd.DataFrame:`
   - `df = pd.read_csv(csv_path, comment='#')`
   - Assert `set(df['attack']) == set(ATTACK_ORDER)` else raise `ValueError(f"CSV attack set mismatch: got {sorted(set(df['attack']))} expected {sorted(ATTACK_ORDER)}")`.
   - Assert `set(df['device']) == set(DEVICE_ORDER)` else raise similarly.
   - Assert `len(df) == 10` else raise `ValueError(f"Expected 10 rows, got {len(df)}")`.
   - Return df.

6. Helper `def _plot(df: pd.DataFrame, out_path: str) -> None:`
   - `apply_ieee_style()`
   - Use `single_col_fig()` for a half-page-friendly figure (3.487 in wide) — Phase 6 will decide column placement; single-col is the safer default.
   - x-axis indices: `x = np.arange(len(ATTACK_ORDER))`.
   - bar width: `w = 0.38`.
   - For each device d in DEVICE_ORDER:
     - Build aligned arrays in ATTACK_ORDER order:
       `means = [df[(df.attack==a) & (df.device==d)]['mean_ms_per_sample'].iloc[0] for a in ATTACK_ORDER]`
       `stds  = [df[(df.attack==a) & (df.device==d)]['std_ms_per_sample'].iloc[0] for a in ATTACK_ORDER]`
     - offset: `dx = -w/2 if d == 'cpu' else +w/2`
     - `ax.bar(x + dx, means, width=w, yerr=stds, capsize=2, color=DEVICE_COLORS[d], label=DEVICE_DISPLAY[d], edgecolor='black', linewidth=0.4, error_kw={'linewidth': 0.5})`
   - Axis setup:
     - `ax.set_yscale('log')`
     - `ax.set_xticks(x)`
     - `ax.set_xticklabels([ATTACK_DISPLAY[a] for a in ATTACK_ORDER])`
     - `ax.set_ylabel('Latency (ms/sample)')`
     - `ax.set_xlabel('Attack')`
     - `ax.grid(True, axis='y', which='both', alpha=0.3, linewidth=0.3)`
     - `ax.legend(loc='upper left', frameon=False)`
   - `plt.tight_layout()`
   - `os.makedirs(os.path.dirname(out_path), exist_ok=True)`
   - `plt.savefig(out_path)`
   - `plt.close()`
   - `print(f"Wrote {out_path}")`

7. Helper `def main() -> int:`
   - argparse: `--csv` (default None -> _resolve_default_csv()), `--out` (default `paper/latex/figures/attack_bench_latency.pdf`, resolved relative to repo root).
   - Resolve repo root as `os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))` (paper/scripts/<file> -> paper/scripts -> paper -> repo).
   - If csv path is relative, anchor it to repo root.
   - If out path is relative, anchor it to repo root.
   - Load, validate, plot. Return 0.

8. Bottom of file:

   ```python
       sys.exit(main())
   ```
