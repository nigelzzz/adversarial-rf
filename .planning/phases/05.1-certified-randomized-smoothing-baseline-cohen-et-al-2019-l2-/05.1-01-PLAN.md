```python
import torch

```

Implement class `SmoothedClassifier`:
  - `ABSTAIN = -1` class attribute.
  - `__init__(self, base_classifier, num_classes: int, sigma: float, device=None)`.
  - `certify(self, x, n0, n, alpha, batch_size) -> (int, float)`:
      1. `self.base_classifier.eval()`
      2. `counts_selection = self._sample_noise(x, n0, batch_size)`; `cAHat = int(counts_selection.argmax())`
      3. `counts_estimation = self._sample_noise(x, n, batch_size)` (SEPARATE draw — fresh randomness, Cohen's independence requirement)
      4. `nA = int(counts_estimation[cAHat])`
      5. `pABar = self._lower_confidence_bound(nA, n, alpha)`
      6. if `pABar < 0.5`: return `(SmoothedClassifier.ABSTAIN, 0.0)` else return `(cAHat, self.sigma * norm.ppf(pABar))`
  - `predict(self, x, n, alpha, batch_size) -> int`:
      counts = `_sample_noise(x, n, batch_size)`; take top-2 counts; if
      `binomtest(count1, count1 + count2, p=0.5).pvalue > alpha` return `ABSTAIN` else return top-1 index.
  - `_sample_noise(self, x, num, batch_size) -> np.ndarray`: AWN-specific per research doc `_sample_noise_awn`.
      Accepts a single sample `x` of shape `[2, T]` (or `[1, 2, T]`); replicate to `this_bs` copies,
      add `torch.randn_like(batch) * self.sigma` in RAW-IQ units, forward through base_classifier,
      UNWRAP `logit, _regu_sum = self.base_classifier(batch + noise)`, `preds = logit.argmax(dim=1)`,
      accumulate `torch.bincount(preds, minlength=self.num_classes)`. Wrap in `torch.no_grad()`.
      Return an `np.ndarray[int]` of length `num_classes`.
  - `_lower_confidence_bound(self, NA: int, N: int, alpha: float) -> float`:
      `if NA == 0: return 0.0` else `return float(beta_dist.ppf(alpha, NA, N - NA + 1))`.
      Do NOT use `alpha/2` or `2*alpha` — the one-sided `alpha` is already correct (research Anti-Patterns).

Add a small module-level helper `smoothed_from_awn(model, num_classes=11, sigma=..., device=...)`
that returns a `SmoothedClassifier` — convenience for RS-03. Keep the public `certify`/`predict`
surface exactly as the locked spec above.
