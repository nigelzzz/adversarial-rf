**Logic:**

Budget curves aggregate accuracy across ALL SNR points (or a specified subset via target_snrs — default to SNR_POINTS=[0,2,...,18]). For each perturbation strength, the evaluation runs the attack at that strength, applies each defense, and records the overall accuracy (averaging across selected SNR points).

1. `model.eval()`. Set up Model01Wrapper with minmax.
2. Create output directory: `budget_dir = os.path.join(cfg.result_dir, 'defense_compare', 'budget_curves')` with `os.makedirs(budget_dir, exist_ok=True)`.
3. Initialize `results = []` list.
4. If `target_snrs` is None, use `SNR_POINTS`.

**Part A: Linf budget curves (per D-06)**

For each `eps` in `linf_epsilons` (default `LINF_EPSILONS`):
  a. Temporarily override `cfg.attack_eps = eps` (save original, restore after).
  b. For each `attack_name` in LINF_ATTACKS:
    - Create attack: `atk = create_attack(attack_name, wrapped_model, cfg)`.
    - For each SNR in target_snrs:
      * Filter test data to SNR, cap per D-04.
      * Generate adversarial examples (same batch loop as run_defense_compare).
      * For each defense in DEFENSE_CONFIGS:
        - Apply defense and get predictions.
        - Compute accuracy.
        - Append to results: `{'attack': attack_name, 'param_name': 'eps', 'param_value': eps, 'snr': snr, 'defense': defense_name, 'accuracy': acc, 'n_samples': n}`.
  c. Restore original cfg.attack_eps.

**Part B: Optimization attack budget curves (per D-07, D-08)**

For each `c_val` in `opt_c_values` (default `OPT_C_VALUES`):
  a. Temporarily override:
     - `cfg.cw_c = c_val` (for CW)
     - `cfg.ead_initial_const = c_val` (for EAD-L1, EAD-EN — note: EAD's initial_const controls attack strength similarly to CW's c)
     Save originals and restore after.
  b. For each `attack_name` in OPT_ATTACKS:
    - Create attack: `atk = create_attack(attack_name, wrapped_model, cfg)`.
    - For each SNR in target_snrs:
      * Same pattern: filter, cap, generate adversarial, evaluate each defense, record results.
    - Append results with `'param_name': 'c', 'param_value': c_val`.
  c. Restore original cfg values.

**Output:**
5. Build DataFrame from results.
6. Save full detail CSV: `budget_dir/budget_curves_detail.csv` (all rows: attack, param_name, param_value, snr, defense, accuracy, n_samples).
7. Compute aggregated budget curves: for each (attack, param_value, defense), compute weighted average accuracy across SNR points.
8. Save aggregated CSV: `budget_dir/budget_curves_agg.csv` (columns: attack, param_name, param_value, defense, accuracy).
9. Also save per-attack CSVs for easy plotting: `budget_dir/budget_{attack}.csv` — pivot table with param_value as rows, defenses as columns.
10. Log summary: for each attack, log the accuracy at the first and last perturbation point for no_defense and ae_fft_topk.
11. Return full DataFrame.

- Use `copy.copy(cfg)` approach is risky since Config is complex. Instead, save original values, modify, then restore in finally block.
- For EAD attacks: check how create_attack reads EAD parameters. In sigguard_eval.py, EAD reads `cfg.ead_kappa`, `cfg.ead_lr`, `cfg.ead_max_iterations`, `cfg.ead_binary_search_steps`, `cfg.ead_initial_const`, `cfg.ead_beta`. The budget curve should vary `cfg.ead_initial_const` which is the initial constant used in binary search and effectively controls attack strength (similar to c in CW).
- Actually re-examine: for CW the "c" parameter is the confidence/cost tradeoff. For EAD, `initial_const` serves a similar role. But per D-07/D-08 the user specified varying "confidence c" for both — so use cfg.cw_c for CW (which maps to torchattacks.CW(c=...)) and for EAD vary `cfg.ead_initial_const` (which maps to torchattacks.EADL1(initial_const=...)).
