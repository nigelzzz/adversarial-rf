**`_apply_defense()` helper function:**
```python
def _apply_defense(defense_name, x_adv, model, detector, cfg, logger):
    """Apply a defense to adversarial signals and return predictions.

    For 'no_defense': run model directly on x_adv.
    For 'ae_fft_topk': use defend() with detector gate.
    For 'rand_smooth': use randomized_smoothing_predict().
    For classical filters + fft_topk + spectral_gated:
        apply DEFENSE_REGISTRY[name](x_adv, **params) then classify.

    Returns: predictions tensor [N] int64
    """
```

The `_apply_defense` function must:
- For `no_defense`: `model(x_adv)` -> argmax
- For `ae_fft_topk`: call `defend(x_adv, model, detector, cfg)` which returns `(preds, latency)` — use preds
- For `rand_smooth`: call `randomized_smoothing_predict(model, x_adv)`
- For other defenses: look up `DEFENSE_REGISTRY[defense_name]`, call it on `x_adv` with cfg-derived kwargs (same pattern as `_apply_filter` in defense_registry.py), then classify filtered signal with `model(filtered)` -> argmax

**`_get_filter_kwargs()` helper:** Extract filter-specific kwargs from cfg for classical filters (same logic as `_apply_filter` in defense_registry.py):

- wiener: `noise=cfg.wiener_noise` (default 0.01), `filter_len=cfg.wiener_filter_len` (default 5)
- savitzky_golay: `window_length=cfg.sg_window_length` (default 11), `polyorder=cfg.sg_polyorder` (default 3)
- gaussian: `sigma=cfg.gaussian_sigma` (default 1.0)
- fir: `cutoff=cfg.fir_cutoff` (default 0.1), `numtaps=cfg.fir_numtaps` (default 31)
- fft_topk: `topk=cfg.def_topk` (default 50)

**`run_defense_compare()` main function signature:**
```python
def run_defense_compare(
    model: nn.Module,
    sig_test: torch.Tensor,
    lab_test: torch.Tensor,
    SNRs: np.ndarray,
    test_idx: np.ndarray,
    cfg,
    logger,
    detector=None,
    attacks: Optional[List[str]] = None,
    snr_points: Optional[List[int]] = None,
    max_per_cell: int = 200,
    batch_size: int = 64,
) -> pd.DataFrame:
```

**Core loop logic:**
1. Set `model.eval()`. Load detector if `cfg.detector_ckpt` is set and detector is None.
2. Set up Model01Wrapper with minmax mode (per D-05: `ta_box='minmax'`).
3. For each `attack_name` in attacks (default ATTACKS):
   a. Log attack name.
   b. Create attack object via `create_attack(attack_name, wrapped_model, cfg)`.
   c. For each `snr` in snr_points (default SNR_POINTS):
      - Filter test data to this SNR using SNRs and test_idx (same pattern as Run_Eval in evaluation.py: `test_SNRs = np.array([SNRs[i] for i in test_idx]); mask = test_SNRs == snr`).
      - Sub-sample to `max_per_cell` per (SNR, modulation) combination (per D-04): group by label, take min(count, max_per_cell // n_mods) per group; if simpler, just cap total at `max_per_cell * n_mods_present`.
      - Actually use simpler approach: cap per-modulation to `max_per_cell` samples. Group indices by label value, take first `max_per_cell` from each group.
      - Batch the selected signals in chunks of `batch_size`.
      - For each batch:
        * Convert to minmax: `x_01, a, b = iq_to_ta_input_minmax(batch_sig.to(device))`
        * Set wrapper minmax: `wrapped_model.set_minmax(a, b)`
        * Generate adversarial: `x_adv_01 = attack(x_01, batch_lab.to(device))`
        * Convert back: `x_adv = ta_output_to_iq_minmax(x_adv_01, a, b)`
      - Concatenate all adversarial batches for this SNR.
      - For each `defense_name` in DEFENSE_CONFIGS:
        * Apply defense and get predictions.
        * Compute accuracy = `accuracy_score(labels, preds)`.
        * Store result: `results.append({'attack': attack_name, 'snr': snr, 'defense': defense_name, 'accuracy': accuracy, 'n_samples': len(labels)})`.
4. Build DataFrame from results list.
5. Compute weighted average column: for each (attack, defense) pair, average accuracy across SNR points weighted by n_samples.
6. Save CSV to `os.path.join(cfg.result_dir, 'defense_compare', 'defense_compare.csv')`.
7. Also produce a pivot table per attack (per D-09): rows=defenses, columns=SNR points + 'weighted_avg'. Save each as `defense_compare_{attack}.csv`.
8. Bold-best formatting: for each column, identify the defense with highest accuracy and note it in a separate `_best.csv` file (or just log it — Phase 3 handles rendering).
9. Return the full DataFrame.

**Important details:**
- Use `torch.no_grad()` for all defense and classification calls.
- Handle CW/EAD attacks which don't use eps (they use `c` parameter) — already handled by create_attack reading `cfg.cw_c`.
- For ae_fft_topk defense: ensure `cfg.detector_threshold` is set (default 0.004468). Load detector from `cfg.detector_ckpt` if provided.
- For no_defense: skip filter step entirely, just classify adversarial directly.
- Log progress: `logger.info(f"Attack={attack_name} SNR={snr} Defense={defense_name} Acc={accuracy:.4f}")`.
- Create output directory `os.path.join(cfg.result_dir, 'defense_compare')` with `os.makedirs(..., exist_ok=True)`.

Add `__all__ = ['run_defense_compare', 'ATTACKS', 'SNR_POINTS', 'DEFENSE_CONFIGS']`.
