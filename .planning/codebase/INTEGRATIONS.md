## Data Storage

**Databases:**
- Local filesystem only - No database server

**File Storage:**

**Primary Datasets (Local):**
- `./data/RML2016.10a_dict.pkl` - RadioML 2016.10a signal data (pickle format)
  - Client: Python pickle module
  - Format: Dictionary with keys `(modulation_bytes, snr_int)`
  - Size: ~500MB
  - Loading: `data_loader/data_loader.py:Load_Dataset()`

- `./data/RML2016.10b.dat` - RadioML 2016.10b signal data (pickle format)
  - Client: Python pickle module
  - Format: Dictionary keyed by (mod, snr) tuples
  - Size: ~3GB
  - Loading: `data_loader/data_loader.py:Load_Dataset()`

- `./data/GOLD_XYZ_OSC.0001_1024.hdf5` - RadioML 2018.01a signal data (HDF5 format)
  - Client: h5py library
  - Structure: Datasets `X` (signals [N, 2, 1024]), `Y` (labels [N, 24]), `Z` (SNR [N])
  - Size: ~3GB
  - Loading: `data_loader/data_loader.py:Load_Dataset()` (h5py.File interface)

**Generated Synthetic Data:**
- `./data/synth_2016.10a.pkl` - Synthetic IQ signals generated by `synth_finetune.py`
  - Format: Dictionary matching RML2016 structure
  - Generation: `util/synth_txrx.py:make_rml_like_burst()`

**Model Checkpoints (Local):**
- `./checkpoint/2016.10a_AWN.pkl` - Trained AWN model for RML2016.10a
  - Format: PyTorch state_dict
  - Size: ~500MB
  - Loading: `torch.load(ckpt_path, map_location=device, weights_only=True)`

- `./checkpoint/2016.10b_AWN.pkl` - Trained AWN model for RML2016.10b
  - Size: ~500MB

- `./checkpoint/2018.01a_AWN.pkl` - Trained AWN model for RML2018.01a
  - Size: ~1.5GB

- `./checkpoint/2016.10a_AWN_ft.pkl` - Finetuned AWN model (synthetic + real data)
  - Generated by: `synth_finetune.py --mode finetune`

- `./checkpoint/detector_ae.pth` - Autoencoder detector for adversarial detection
  - Format: PyTorch state_dict
  - Trained by: `main.py --mode train_detector`
  - Used in: `util/defense.py:normalize_iq_data()` with `ae_fft_topk` defense

## Dataset & Benchmark Sources

**Radio Modulation Library (RML):**
- RML2016.10a - 11 modulation classes (BPSK, QPSK, 8PSK, QAM16, QAM64, PAM4, CPFSK, GFSK, WBFM, AM-DSB, AM-SSB)
  - 220K samples, 128 I/Q samples per signal
  - SNR range: -20 to 18 dB
  - Source: https://www.deepsig.io/datasets (RadioML 2016.10a)

- RML2016.10b - 10 modulation classes (excludes AM-SSB)
  - 1.2M samples
  - Same SNR and signal length as 10a

- RML2018.01a - 24 modulation classes (extended set including APSK variants)
  - 2.5M samples, 1024 I/Q samples per signal
  - SNR range: -20 to 32 dB
  - Source: https://www.deepsig.io/datasets (GOLD dataset)

**Synthetic Data Generation:**
- Custom TX/RX chain: `util/synth_txrx.py`
  - Modulation: BPSK, QPSK, 8PSK, QAM16, QAM64, PAM4, CPFSK, GFSK
  - Pulse shaping: RRC filter (β=0.35)
  - Channel impairments: Random phase, gain jitter, CFO, multipath
  - Presets: `clean`, `phase_gain`, `phase_gain_cfo`, `full`, `rml_like`

## Integration Notes

**Attack Framework (torchattacks):**
- Default mode: `--attack_backend torchattacks` uses library implementation
- Fallback: `--attack_backend internal` uses custom CW implementation in `util/adv_attack.py:cw_l2_attack()`
- Input normalization: Two modes for epsilon interpretation
  - `unit` mode: `(x+1)/2` normalization to [0,1] space (requires small eps ~0.03)
  - `minmax` mode: Per-sample min-max normalization to [0,1] (allows larger eps values)

**Data Format Conversions:**
- Pickle → PyTorch Tensor: `pickle.load()` → `np.asarray()` → `torch.from_numpy()`
- HDF5 → PyTorch Tensor: `h5py.File()` → direct numpy array access → `torch.from_numpy()`
- Signal dimension handling: Input `[batch, 2, time_len]` (I/Q pairs)

**Checkpoint Management:**
- Model saving: `torch.save(model.state_dict(), path)`
- Model loading: `model.load_state_dict(torch.load(path, map_location=device, weights_only=True))`
- Detector loading: Same pattern, separate from main model
