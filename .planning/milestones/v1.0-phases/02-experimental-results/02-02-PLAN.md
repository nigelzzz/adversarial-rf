**Logic:**
1. `model.eval()`. Set up Model01Wrapper with minmax mode.
2. Create output directory: `confmat_dir = os.path.join(cfg.result_dir, 'defense_compare', 'confmat')` with `os.makedirs(confmat_dir, exist_ok=True)`.
3. Get class labels: `mod_names = list(cfg.classes.keys())` and `n_classes = len(mod_names)` (should be 11).
4. `results = {}` dict to collect all confusion matrices.
5. For each `attack_name` in `confmat_attacks` (default CONFMAT_ATTACKS):
   a. Create attack object via `create_attack(attack_name, wrapped_model, cfg)`.
   b. For each `snr` in `confmat_snrs` (default CONFMAT_SNRS):
      - Filter test data to this SNR (same pattern as run_defense_compare).
      - Cap per-modulation at `max_per_cell` samples (per D-04).
      - Generate adversarial examples for all selected samples (same batch loop as run_defense_compare).
      - **Before defense (no_defense):**
        * Classify adversarial directly: `model(x_adv)` -> argmax -> `preds_before`.
        * Compute confusion matrix: `cm_before = confusion_matrix(labels_np, preds_before_np, labels=list(range(n_classes)))`.
        * Row-normalize to percentages (per D-16): `cm_before_pct = cm_before.astype(float) / cm_before.sum(axis=1, keepdims=True).clip(min=1) * 100.0`.
        * Save raw: `np.save(os.path.join(confmat_dir, f'{attack_name}_snr{snr}_before.npy'), cm_before)`.
        * Save row-normalized CSV: create DataFrame with mod_names as index and columns, save to `{attack_name}_snr{snr}_before_pct.csv`.
        * Store in results dict: `results[f'{attack_name}_snr{snr}_before'] = cm_before`.
      - **After defense (ae_fft_topk unified pipeline):**
        * Apply unified pipeline defense: call `defend(x_adv, model, detector, cfg_with_defense)` where cfg_with_defense has `defense='fft_topk'` and `detector_threshold` set.
        * If detector is None, fall back to just applying fft_topk filter without detector gate.
        * Get predictions from defend() return value.
        * Compute confusion matrix: `cm_after = confusion_matrix(labels_np, preds_after_np, labels=list(range(n_classes)))`.
        * Row-normalize: same as above.
        * Save raw: `np.save(os.path.join(confmat_dir, f'{attack_name}_snr{snr}_after.npy'), cm_after)`.
        * Save CSV: `{attack_name}_snr{snr}_after_pct.csv`.
        * Store: `results[f'{attack_name}_snr{snr}_after'] = cm_after`.
      - Log: `logger.info(f"Confmat {attack_name} SNR={snr}: before_acc={before_acc:.4f} after_acc={after_acc:.4f}")`.
6. Save a summary CSV listing all 18 matrices with their diagonal accuracy: columns = `[attack, snr, condition, accuracy]`.
7. Return results dict.

**Important implementation details:**
- Use `from sklearn.metrics import confusion_matrix` (already imported).
- Row normalization: `cm_pct = cm.astype(np.float64); row_sums = cm_pct.sum(axis=1, keepdims=True); row_sums[row_sums == 0] = 1; cm_pct = cm_pct / row_sums * 100.0`.
- For the "after defense" case, temporarily set cfg attributes: `cfg.defense = 'fft_topk'` and `cfg.def_topk = getattr(cfg, 'def_topk', 50)`, then call `defend(x_adv, model, detector, cfg)`.
- After calling defend, restore original cfg.defense value.
- The confusion matrix labels= parameter must be `list(range(n_classes))` to ensure all 11 classes appear even if some have zero samples at that SNR.
- Byte-string keys in cfg.classes: use `[k.decode() if isinstance(k, bytes) else str(k) for k in cfg.classes.keys()]` for CSV headers.
