PARAM_GRIDS = {

**Part B: `calibrate_filter(defense_name, param_grid, val_signals, val_labels, model, attack_fn, snr_value, alpha=0.5)`** (per D-01/D-02/D-03)
- For each param set in `param_grid`:
  - Apply filter with those params to clean val signals: `x_filtered = fn(val_signals, **params)`.
  - Classify: `logits, _ = model(x_filtered); clean_acc = (logits.argmax(1) == val_labels).float().mean()`.
  - Generate adversarial examples: `x_adv = attack_fn(val_signals, val_labels)`.
  - Apply filter to adversarial: `x_adv_filtered = fn(x_adv, **params)`.
  - Classify: `defended_acc = (model(x_adv_filtered)[0].argmax(1) == val_labels).float().mean()`.
  - Composite score per D-02: `score = alpha * clean_acc + (1 - alpha) * defended_acc`.
- Return `(best_params, best_score)`.
- Use `functools.partial` to look up filter: `fn = DEFENSE_REGISTRY[defense_name]` then apply kwargs.
- Limit val set to 200 samples per SNR to keep CW tractable (per Research pitfall 5).

**Part C: `run_calibration_sweep(model, dataset_loader, cfg, attack_fn, alpha=0.5)`** (per D-03: per-SNR)
- Loop over each SNR in dataset.
- For each filter name in PARAM_GRIDS:
  - Extract val data at this SNR.
  - Call `calibrate_filter(...)`.
  - Store result in `results[filter_name][snr] = best_params`.
- Save results to JSON: `inference/<dataset>_*/result/calibration_params.json`.
- Print summary table.

**Part D: `run_latency_benchmark(model, detector, cfg, batch_size=32)`** (per PIPE-02, D-11/D-12/D-13/D-14)
- Create dummy batch `x = torch.randn(batch_size, 2, 128, device='cuda')`.
- For each defense in DEFENSE_REGISTRY (excluding rand_smooth):
  - Warmup: 10 calls (per D-13).
  - GPU-native filters (gaussian, fir, fft_topk, spectral_gated): use `torch.cuda.Event`, 50 measurement iterations.
  - CPU filters (kalman, wiener, savitzky_golay): use `time.perf_counter`, 20 iterations.
  - Record per-sample ms = total_ms / (n_iters * batch_size) (per D-12).
- For rand_smooth: time full `randomized_smoothing_predict(model, x, k=20, sigma=0.01)`, divide by batch_size.
- For detector: time `detector(normalize_for_detector(x))`, divide by batch_size.
- For classifier: time `model(x)[0]`, divide by batch_size.
- Print formatted table and return dict.
- Also benchmark at batch_size=1 for single-sample latency.

**Part E: `validate_clean_accuracy(model, detector, cfg, test_signals, test_labels, SNRs, test_idx)`** (per PIPE-03)
- For each defense in DEFENSE_REGISTRY keys + 'rand_smooth':
  - Set `cfg.defense = defense_name`.
  - Run `defend(test_signals, model, detector, cfg)` -> predictions.
  - Compute accuracy: `(predictions == test_labels).float().mean()`.
- Compare each defense accuracy to baseline (no defense) accuracy.
- Flag any defense where drop > 2% (PIPE-03 threshold).
- Print comparison table.
- Return `{defense_name: accuracy}` dict.
