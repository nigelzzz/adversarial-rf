Create `util/defense_baselines.py` with these five functions. All accept `x: torch.Tensor` of shape `[N, 2, T]` and return same shape on same device.

**1. `kalman_filter(x, *, process_noise=1e-4, meas_noise=0.01)`** (per D-04: process/measurement noise)
- Internal helper `_kalman_1d(signal, q, r)` implements scalar constant-velocity Kalman: init x_est=signal[0], p=1.0; loop over T with predict/update steps.
- Outer function: `x.detach().cpu().numpy().astype(np.float32)`, loop over N and C=2 channels, call `_kalman_1d`, return `torch.from_numpy(out).to(device=x.device, dtype=x.dtype)`.
- CPU-only path (no pykalman/filterpy available).

**2. `wiener_filter(x, *, noise=0.01, filter_len=5)`** (per D-04: noise variance, filter length)
- Use `scipy.signal.wiener(arr[n,c], mysize=filter_len, noise=noise)` per sample per channel.
- Same CPU numpy pattern as Kalman.

**3. `sg_filter(x, *, window_length=11, polyorder=3)`** (per D-04: window size, polynomial order)
- Enforce constraints: if window_length even, add 1; ensure window_length > polyorder via `max(window_length, polyorder+2)` (must be odd AND > polyorder).
- Use `scipy.signal.savgol_filter(arr, window_length=wl, polyorder=po, axis=-1)` — operates on full [N,2,T] array at once (vectorized, no per-sample loop).

**4. `gaussian_filter(x, *, sigma=1.0)`** (per D-04: sigma) — GPU-NATIVE (per D-11, anti-pattern avoidance)
- Kernel size = `int(6.0 * sigma + 1.0)`, ensure odd.
- Build 1D Gaussian kernel on x.device: `t = torch.arange(-half, half+1, ...)`, `gauss = torch.exp(-t**2 / (2*sigma**2))`, normalize to sum=1.
- Expand to `[2, 1, ksize]` for depthwise conv1d. Pad with `F.pad(x, (half, half), mode='reflect')`.
- Return `F.conv1d(x_padded, kernel, groups=2)`. NEVER call `.cpu()` or `.numpy()`.

**5. `fir_filter(x, *, cutoff=0.1, numtaps=31)`** (per D-04: cutoff frequency, filter order) — GPU-NATIVE
- Ensure numtaps is odd. Design coefficients on CPU via `scipy.signal.firwin(numtaps, cutoff, window='hamming')`.
- Move to GPU: `torch.tensor(coeffs, dtype=x.dtype, device=x.device).view(1,1,-1).expand(2,1,-1)`.
- Pad reflect, apply `F.conv1d(..., groups=2)`. Coefficients computed once per call (not cached — calibration changes params).
