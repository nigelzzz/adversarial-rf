% ---- Abstract ----
\begin{abstract}
Deep-learning-based automatic modulation classifiers (AMC) achieve
high accuracy under benign channel conditions but are vulnerable to
adversarial perturbations crafted by optimization-based attacks.
We propose an adaptive spectral defense pipeline that first detects
adversarial inputs using an autoencoder anomaly score and then
applies an FFT Top-K recovery operator gated by that score.
Evaluated on RML2016.10a against five attacks (CW, EAD-L1, EAD-EN,
FGSM, PGD), the unified pipeline recovers up to 79.8\% accuracy
compared with 75.6\% for the undefended model, while incurring only
sub-millisecond latency overhead.

\end{abstract}
