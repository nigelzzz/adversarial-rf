# NDSS 投稿规划：论文结构与实验补充方案

## 论文定位

**标题（暂定）**：Control-Plane Denial of Service: Adversarial Attacks on Automatic Modulation Classification in Software-Defined Radio Receivers

**核心论点**：对抗性攻击针对AMC分类器是一种**控制面拒绝服务攻击**——它不破坏信号波形（数据面完整），而是通过误导调制识别导致接收端选择错误的解调器，从而造成链路中断。这种攻击比传统干扰效率高6-24 dB。

**投稿会议**：NDSS (Network and Distributed System Security Symposium)

---

## 一、论文结构规划

### 1. Abstract（摘要）

**要点**：
- 问题：SDR接收机越来越依赖ML进行自动调制分类（AMC）
- 发现：对抗性扰动造成控制面DoS（CRC通过率从99%降至<8%），但数据面完好（Oracle解调CRC仍93%+）
- 效率：比传统干扰节省6-24 dB功率
- 防御评估：FFT Top-K、对抗训练、FEC均无法完全防御
- 结论：AMC是SDR系统的关键安全薄弱环节

### 5. Methodology（方法论）~2页

#### 5.1 控制面 vs 数据面验证框架

**四象限CRC验证**：

```
                    Oracle解调器          AMC解调器
                    （已知真实调制）       （分类器预测调制）
┌──────────────────────────────────────────────────┐
│ 无攻击 (Clean)  │  Clean+Oracle         Clean+AMC       │
│ 有攻击 (Adv)    │  Adv+Oracle           Adv+AMC         │
└──────────────────────────────────────────────────┘
```

- **Adv+Oracle CRC高 + Adv+AMC CRC低** → 证明攻击仅作用于控制面
- **Adv+Oracle CRC低** → 攻击同时破坏数据面

**已有素材**：`crc_experiment_content.tex` Section 2-3

#### 5.2 合成突发信号流水线

```
TX: 数据比特 → CRC-8 → [FEC编码] → 调制 → 脉冲成形(RRC) → 信道(AWGN+CFO)
RX: 匹配滤波 → 导频恢复 → 解调 → [FEC译码] → CRC校验
```

**已有实现**：`util/synth_txrx.py`

#### 5.3 攻击方法

- CW (Carlini-Wagner L2) — 主要攻击
- FGSM、PGD — 梯度攻击基线
- 17种torchattacks攻击全面评估

#### 5.4 防御方法

- FFT Top-K频谱滤波
- 自编码器异常检测 + 门控Top-K
- 对抗训练（PGD-AT）← **需补充**
- FEC编码（卷积码+Viterbi）

### 8. Discussion（讨论）~1页

- **为什么防御困难**：CW扰动频谱与信号重叠（99.7%能量在Top-50 FFT bins内）
- **FEC的局限**：改善数据面但不解决控制面问题
- **实际影响**：军事/商业SDR系统的安全隐患
- **与传统干扰的关系**：对抗攻击是"智能干扰"，效率远超暴力干扰
- **缓解建议**：集成学习、输入随机化、物理层认证
