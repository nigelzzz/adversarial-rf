# Adaptive-K v1 vs v2 vs v2-SNR 比較報告

## 概述

本報告比較三種 Adaptive-K FFT Top-K 防禦的 K 選擇策略。三者共享相同的核心原理——保留信號主要頻譜成分、移除對抗擾動——但在 K 的估算與控制上有本質差異。

## 演算法比較

### v1：純膝點（Knee Only）

```
輸入 x[N, 2, 128]
    │
    ▼
FFT → 排序 |X| 降序
    │
    ▼
找到第一個 |X[k]|/|X[0]| < 5% 的索引
    │
    ▼
K = 該索引（無上限，範圍 1~128）
    │
    ▼
保留 top-K 頻帶，其餘歸零 → IFFT
```

**一條路徑、一個規則、所有調變一視同仁。**

### v2-fixed：膝點 + 固定上限 + 頻譜路由

```
輸入 x[N, 2, 128]
    │
    ▼
FFT（計算一次，共享給所有步驟）
    │
    ├──► 頻譜平坦度 = 幾何平均(PSD) / 算術平均(PSD)
    │         │
    │    平坦度 > 0.4 ? ──是──► 寬頻路徑：32 階量化 → 完成
    │         │
    │        否（窄頻）
    │         │
    ├──► 膝點估算（與 v1 相同的 5% 門檻）
    │         │
    ▼         ▼
K = min(膝點, 20)    ← 固定上限
    │
    ▼
保留 top-K 頻帶 → IFFT
```

### v2-SNR：膝點 + SNR 自適應上限 + 頻譜路由

```
輸入 x[N, 2, 128]
    │
    ▼
FFT（計算一次，共享）
    │
    ├──► 頻譜平坦度路由（同 v2-fixed）
    │         │
    │    平坦度 > 0.4 → 量化 32 階 → 完成
    │         │
    ├──► 膝點估算（5% 門檻）
    │         │
    ├──► SNR 估算 = top-10 頻帶能量 / 其餘頻帶能量
    │         │
    │    SNR → k_max 線性內插：
    │         SNR ≤ 3  → k_max = 35（溫和，保護弱信號）
    │         SNR ≥ 10 → k_max = 20（激進，最大化攻擊移除）
    │         │
    ▼         ▼
K = min(膝點, k_max)    ← 自適應上限
    │
    ▼
保留 top-K 頻帶 → IFFT
```

## v1 的核心問題：膝點高估

CW 攻擊在整個頻譜添加擾動能量，抬高了排序幅度曲線的尾部。5% 膝點偵測到的不是「信號頻寬」，而是「信號+攻擊的聯合頻寬」，導致 K 嚴重高估：

| 調變 | v1 膝點 K | Oracle 最佳 K | 高估倍數 |
|------|:---:|:---:|:---:|
| AM-DSB | 54 | 2 | **27 倍** |
| GFSK | 110 | 15 | **7 倍** |
| WBFM | 61 | 10 | **6 倍** |
| PAM4 | 92 | 15 | **6 倍** |
| QAM64 | 39 | 10 | **4 倍** |
| QAM16 | 67 | 20 | **3 倍** |
| QPSK | 124 | 50 | **2.5 倍** |
| BPSK | 124 | 64 | **2 倍** |
| 8PSK | 126 | 64 | **2 倍** |
| CPFSK | 123 | 64 | **2 倍** |
| AM-SSB | 128 | 64 | **2 倍** |

**K 越大 = 保留越多對抗雜訊 = 防禦越弱。** 這是 v1 與 Oracle 之間 11 個百分點差距的主要原因。

## v2 如何解決每個問題

| v1 問題 | v2 修正 | 受益調變 | 範例 |
|---------|---------|---------|------|
| CW 抬高膝點 → K 過大 | **K 上限**限制在 20-35 | QAM64, PAM4, GFSK, QAM16 | GFSK: 110 → 20 |
| AM-SSB 平坦頻譜 → K=128 = 無防禦 | **頻譜路由**送往量化 | AM-SSB | 3.5% → 74.9% |
| 低 SNR 信號弱，相同上限過於激進 | **SNR 自適應上限**低 SNR 放寬 | 所有調變（低 SNR） | SNR=0: 上限 35 vs 20 |
| 窄頻調變本來就需要小 K | **膝點保留**——上限不影響 | AM-DSB, WBFM | AM-DSB: 膝點=6，保留為 6 |

## 實際 K 值分佈

基於 110,000 個 RML2016.10a 樣本（SNR >= 0）的統計：

| 調變 | v1 膝點 K | v2 實際 K | 觸及上限比例 | 膝點生效？ |
|------|:---:|:---:|:---:|:---:|
| AM-DSB | 6.0 | **3.4** | 10.2% | 是——膝點遠低於上限 |
| WBFM | 9.6 | **5.8** | 12.9% | 是——膝點遠低於上限 |
| GFSK | 34.0 | **17.8** | 49.4% | 部分——半數觸及上限 |
| QAM16 | 35.7 | **20.0** | 99.4% | 否——上限主導 |
| QAM64 | 32.2 | **20.0** | 99.2% | 否——上限主導 |
| PAM4 | 36.8 | **19.9** | 92.0% | 否——上限主導 |
| 8PSK | 56.7 | **20.0** | 99.4% | 否——上限主導 |
| BPSK | 52.1 | **19.8** | 91.6% | 否——上限主導 |
| QPSK | 56.0 | **20.0** | 99.2% | 否——上限主導 |
| CPFSK | 55.0 | **20.0** | 99.2% | 否——上限主導 |
| AM-SSB | 128.0 | **量化** | — | 路由至不同防禦 |
| **整體** | **45.7** | **17.0** | **77.5%** | |

**實際結論：v2 對 77.5% 的樣本使用 K=20（上限值），膝點僅對 AM-DSB 和 WBFM 有實質作用。**

## v2-SNR 的 SNR 自適應效果

### 各 SNR 的 K 值變化

| 實際 SNR | v1 膝點 | 估算 SNR | k_max | v2 實際 K | 觸及上限比例 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 dB | 91.2 | 2.9 | 33.6 | 33.3 | 93.6% |
| 2 dB | 70.0 | 4.9 | 30.6 | 27.4 | 71.9% |
| 4 dB | 53.0 | 8.7 | 29.2 | 24.8 | 64.0% |
| 6 dB | 39.9 | 16.6 | 28.6 | 23.7 | 53.6% |
| 8 dB | 35.1 | 34.4 | 28.3 | 22.7 | 44.4% |
| 10+ dB | ~33.4 | >74 | ~28.2 | ~22.3 | ~40% |

**為什麼低 SNR 用更大的 K？**

不是「保留更多雜訊」，而是**保護弱信號**：
- 低 SNR 時信號能量弱且分散在更多頻帶
- K=20 可能切掉真實的信號頻帶（看起來「小」但其實是信號）
- K=35 多保留一些頻帶，代價是留下少量雜訊，但信號完整性更好
- 低 SNR 時攻擊本身也較弱（通道雜訊已提供天然防禦）

## v2 的已知代價

### 寬頻調變的犧牲

v2 的 K 上限對 BPSK、QPSK、8PSK、CPFSK 造成損失，因為這些調變的 Oracle K = 50-64，但被限制在 20：

| 調變 | K=20（v2） | v1 膝點 K | Oracle K | v1 比 v2 好多少 |
|------|:---:|:---:|:---:|:---:|
| BPSK | 80.7% | 85.3% | 89.0% (K=64) | +4.6pp |
| QPSK | 73.8% | 83.7% | 90.4% (K=50) | **+9.9pp** |
| 8PSK | 36.5% | 39.9% | 59.3% (K=64) | +3.4pp |
| CPFSK | 88.7% | 94.4% | 96.7% (K=64) | +5.7pp |

### 為什麼無法用頻譜平坦度區分

理想情況下，可以對寬頻調變使用更大的 K、對窄頻使用小 K。但頻譜平坦度無法可靠區分這兩組：

| 調變 | 平均平坦度 | 應該用大 K？ |
|------|:---:|:---:|
| QAM16 | 0.032 | 否（用 K=20） |
| QAM64 | 0.029 | 否（用 K=20） |
| GFSK | 0.053 | 否（用 K=20） |
| WBFM | 0.060 | 否（用 K=10） |
| CPFSK | **0.062** | **是（需 K=64）** |
| AM-DSB | 0.066 | 否（用 K=6） |
| QPSK | **0.065** | **是（需 K=50）** |
| 8PSK | **0.067** | **是（需 K=64）** |
| BPSK | **0.098** | **是（需 K=64）** |
| AM-SSB | 0.562 | 量化路徑 |

CPFSK（0.062）與 WBFM（0.060）和 AM-DSB（0.066）的平坦度幾乎相同，但需要的 K 完全不同（64 vs 10 vs 6）。無法劃出清晰的門檻值。**這是 v2 做出的根本性取捨：犧牲 4 種寬頻調變各 4-10pp，換取 6 種窄頻調變各 5-70pp 的大幅提升。**

## 計算成本比較

| | v1 | v2-fixed | v2-SNR |
|--|:---:|:---:|:---:|
| FFT | 1 次 | 1 次（共享） | 1 次（共享） |
| IFFT | 1 次 | 1 次 | 1 次 |
| 額外運算 | — | 平坦度（幾個乘除法） | 平坦度 + SNR 估算（幾個乘除法） |
| 需要模型？ | 否 | 否 | 否 |
| 需要標籤？ | 否 | 否 | 否 |
| **總成本** | **~相同** | **~相同** | **~相同** |

三種方法的運算成本幾乎一致——v2 的額外開銷僅是幾次算術運算，可忽略不計。

## 五種攻擊全面比較（加權平均準確率）

| 攻擊 | 無防禦 | v1 | v2-SNR | v2 比 v1 |
|------|:---:|:---:|:---:|:---:|
| CW | 35.4% | 66.6% | **71.3%** | +4.7pp |
| EAD-L1 | 6.6% | 66.2% | **70.8%** | +4.6pp |
| EAD-EN | 3.4% | 62.2% | **67.5%** | +5.3pp |

v2-SNR 在最重要的 L2 攻擊（CW, EAD）上提升 4-5pp，在 FGSM 上持平，PGD 略有提升。

## 總結

### 各版本定位

| 版本 | 策略 | 優勢 | 劣勢 |
|------|------|------|------|
| **v1** | 純膝點，無上限 | 寬頻調變保留更多信號（BPSK +5pp, QPSK +10pp） | CW 抬高膝點致 K 過大；AM-SSB 完全無防禦 |
| **v2-fixed** | 膝點 + K=20 固定上限 + 量化路由 | 大幅改善窄頻調變；AM-SSB 首次可防禦 | 低 SNR 可能過度濾波 |
| **v2-SNR** | 膝點 + SNR 自適應上限 + 量化路由 | 所有 SNR 均優於 v1；低 SNR 增益最大（+10.8pp） | 寬頻調變仍犧牲 4-10pp |

### 論文建議

1. **主要方法**：報告 v2-SNR 作為提出的防禦
2. **消融實驗**：展示 v1 → v2-fixed → v2-SNR 的逐步改進
3. **誠實報告代價**：寬頻調變（BPSK, QPSK, 8PSK, CPFSK）犧牲 4-10pp
4. **核心論述**：v2-SNR 的 K 上限策略將 CW 攻擊的「頻譜膨脹」效應隔離在上限之下，使防禦對攻擊強度不敏感
